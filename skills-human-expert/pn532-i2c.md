---
name: PN532 (I2C mode)
description: An NFC/RFID controller module to read and write tags, configured in I2C mode.
---

## Pinout

| Name | Description |
|---|---|
| 3.3V | Voltage supply |
| SCK | NC in I2C mode |
| MISO | NC in I2C mode |
| MOSI/SDA/TX | I2C data line; needs pull-up |
| SSEL/SCL/RX | I2C clock line; needs pull-up |
| RSTOUT_N | Reset input; active low; optional |
| IRQ | Interrupt Request; optional |
| GND | Ground |
| SEL0_JUMPER | Must configure to ON for I2C |
| SEL1_JUMPER | Must configure to OFF for I2C |

## Operation

- I2C interface with address 0x12
- For Aruidno framework, use `Adafruit_PN532.h` in `Adafruit PN532` library.
    - To read nfc card, use Adafruit_PN532::readPassiveTargetID(PN532_MIFARE_ISO14443A, uint8_t *uid, uint8_t *uidLength).
