---
name: MAX30101 & MAX32664
description: An LED-based Pulse Oximeter (SpO2) and Heart Rate Sensor.
---

## Pinout

| Name | Description |
|---|---|
| GND | Ground |
| 3V3 | 3.3V supply |
| SDA | I2C data line; includes 4.7k pull up onboard |
| SCL | I2C clock line; includes 4.7k pull up onboard |
| ~RST | Reset input; active low; NC if not used |
| ~MFIO | Multifunction IO; asserts low when sensor needs to communicate with host |

## Operation

- I2C interface with address 0x55
- For Arduino framework, use `SparkFun_Bio_Sensor_Hub_Library.h` from `SparkFun Bio Sensor Hub Library`.
    - Instantiate with `SparkFun_Bio_Sensor_Hub(int resetPin, int mfioPin)`. Both pins must be specified for this library to work.
    - Use SparkFun_Bio_Sensor_Hub.begin() to connect, then configure the mode using SparkFun_Bio_Sensor_Hub.configBpm(uint8_t mode). Use MODE_ONE for HR only and MODE_TWO for both HR and SpO2
    - Read with bioData readBpm(); bioData is a struct including the following useful fields:
    ```
    uint16_t heartRate;  // BPM
    uint8_t confidence;  // 0-100%
    uint16_t oxygen;     // 0-100%
    uint8_t status;      // 0: Success, 1: Not Ready, 2: Object Detectected, 3: Finger Detected
    ```
