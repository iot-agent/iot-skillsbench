---
name: INA219
description: A DC current sensor using 0.1 ohm shunt resistor, with 26V +-3.2A measurement range.
---

## Pinout

| Name | Description |
|---|---|
| VIN | Voltage supply, 3-5V, use same voltage as MCU logic level |
| GND | Ground |
| SCL | I2C clock line |
| SDA | I2C data line |
| VIN- | Measurement load to ground|
| VIN+ | Measurement target power supply |

## Operation

- I2C interface with address 0x40
- For Aruidno framework, use `Adafruit_INA219.h` in `Adafruit INA219` library.
    - Initialize with Adafruit_INA219::begin();
    - Relevant functions include float getBusVoltage_V(), float getShuntVoltage_mV(), float getCurrent_mA(), float getPower_mW().
