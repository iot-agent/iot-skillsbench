---
name: LTR390
description: An integrated ambient light sensor (ALS) and ultraviolet light sensor (UVS).
---

## Pinout

| Name | Description |
|---|---|
| VIN | Voltage supply, 3-5V, use same voltage as MCU logic level |
| GND | Ground |
| SCL | I2C clock line |
| SDA | I2C data line |
| INT | Interrupt output for threshold events; optional |

## Operation

- I2C interface with address 0x53
- Two measurement modes: ALS (ambient visible light sensing) and UVS (UV light sensing).
- For Aruidno framework, use `Adafruit_LTR390.h` in `Adafruit LTR390 Library` library.
    - Initialize with Adafruit_LTR390::begin();
    - The sensor has two modes, LTR390_MODE_UVS (for UV measurement), and LTR390_MODE_ALS (for ambient light measurement). The setter and getter are void Adafruit_LTR390::setMode(ltr390_mode_t mode) and ltr390_mode_t Adafruit_LTR390::getMode(void).
    - Check bool Adafruit_LTR390::newDataAvailable() then read with uint32_t Adafruit_LTR390::readUVS(void) or uint32_t Adafruit_LTR390::readALS(void).
